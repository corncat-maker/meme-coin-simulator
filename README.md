# Meme 币庄家模拟器

一款面向移动端的回合制加密货币模拟交易游戏。每推进一回合，游戏时间前进一小时。所有交易、资金与价格均为模拟，不连接真实交易所或钱包。

## 主要功能

- CEX 现货交易：市价/限价订单、盘口、K 线与资产管理。
- 永续合约：多空持仓、分级杠杆、资金费率、强平与 ADL。
- 链上钱包：CEX 充提币、DEX 兑换、添加/撤出流动性与质押借款。
- 市场模拟：AI 交易员、做市商、散户、热度与事件。
- 本地存档、深浅色主题及可离线运行的单文件 HTML。

## 直接体验

- **浏览器版**：下载 [`standalone/index.html`](standalone/index.html) 后用现代浏览器打开；无需安装依赖。
- **Android 版**：到本仓库 **Releases** 下载 `庄家模拟器_1.0.apk`。

Android 安装包由项目作者提供，原样发布，不在本源码仓库中重新签名或构建。当前仓库是 React/Vite Web 项目，不包含 Android 原生封装工程、签名密钥或可复现 APK 的打包流水线。APK 的内容和版本不应仅凭文件名推断为与当前 HTML 完全相同。

## 源码开发

建议使用 Node.js 22 LTS 与 npm。项目保留原有脚手架依赖与构建插件，不在发布过程中修改游戏机制。

```sh
npm ci
npm run dev
```

打开终端打印的本地开发地址。生成生产构建：

```sh
npm run build
npm run typecheck:all
npm run preview
```

生成离线单文件（目标文件必须尚不存在）：

```sh
npm run build
node scripts/pack-offline.mjs standalone/local-build.html
```

```text
standalone/index.html 已验收的钱包交互优化离线版

```
